A high-performance, spatial web experience built to showcase the intersection of **AI Analytics** and **B2B Tech Sales**. Rather than a standard scrolling document, this portfolio utilizes React Three Fiber to render a WebGL environment, allowing users to navigate through different "districts" of my professional background.

## 🎯 The Objective

In modern B2B tech sales and data analytics, the ability to present complex information in an intuitive, engaging format is critical. I architected this 3D environment to demonstrate:
1. **Technical Literacy:** Proficiency with modern deployment pipelines, component-based architecture, and 3D rendering.
2. **Data Storytelling:** Transforming standard resume bullet points into an interactive user experience.
3. **Execution:** Taking a complex concept from wireframe to production using an AI-assisted development workflow (Next.js, Tailwind, Vercel).

## 🗺️ System Architecture & Navigation

The application uses a spatial "Bento Grid" navigation model. Users are placed in a central hub and can navigate to four distinct data endpoints:

* **North (The Tech Hub):** Technical project case studies, including a Deep Learning Multi-Agent System (MAS) and real-time Streamlit data dashboards.
* **East (Analytics Center):** A comprehensive breakdown of my technical stack (Python, React) and specific B2B Sales methodologies.
* **South (Personal District):** Background information, including my BS in AI Analytics from Georgia State University, my base in Atlanta, GA, and a few personal metrics (heavy weightlifting milestones, NBA viewership tracking).
* **West (Comms Station):** Direct routing for professional contact.

## 🛠️ Tech Stack

* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS & Framer Motion
* **3D Rendering:** React Three Fiber (`@react-three/fiber`, `@react-three/drei`)
* **Deployment:** Vercel (CI/CD linked via GitHub)
* **Workflow:** Built utilizing AI-agentic development practices (Claude Code CLI / Cursor).

## 🚀 Getting Started (Local Development)

To run this spatial environment on your local machine:

```bash
# Clone the repository
git clone [https://github.com/SaiPutumbaka/personal-portfolio.git](https://github.com/SaiPutumbaka/personal-portfolio.git)

# Navigate into the directory
cd personal-portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev

Open http://localhost:3000 with your browser to explore the environment.
